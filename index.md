## What is HAModLoader?

HAModLoader (Hybrid Animals Mod Loader) is a mod loader for the mobile game *Hybrid Animals*. Started on March 17, 2025, it is the first mod loader for the game. It consists of multiple components:

* [FusionCore](https://github.com/All-Of-Us-Mods/FusionCore) — The main program required to load mods.
* [HAModHelper](https://github.com/eris-webserv/HAModHelper) — A plugin that reimplements multiplayer and unveils APIs for modders.
* [HAMultiplayer](https://github.com/eris-webserv/HAMP) — An optional server software reimplementation for hosting custom servers.
