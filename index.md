# What is HAModLoader?

HAModLoader (or Hybrid Animals Mod Loader) is, well, a mod loader for the mobile game, Hybrid Animals. This project started on 17th of March 2025 being the first mod loader for the game. It is made out of multiple components:
* [FusionCore](https://github.com/All-Of-Us-Mods/FusionCore) - The main program you need to install to load mods
* [HAModHelper](https://github.com/eris-webserv/HAModHelper) - Mod/Plugin that reimplements multiplayer and 
unvails API that modders can use to make their mods (see [API](../api/HAModHelper.GamePlugin.Base.Events.html) section for more details)
* [HAMultiplayer](https://github.com/eris-webserv/HAMP) (optional component) - Reimplementation of Hybrid Animals's server software for HAModHelper; used to host servers
